# 简历项目包装文案与 15 道面试高频灵魂拷问通关指南

## 一、STAR 法则简历项目经历模板（可直接按岗位微调）

### 1. PLC 电气自动化工程师方向
- **项目名称**：基于西门子 S7-1215C + PROFINET 的新能源锂电模组柔性视觉分拣、热压固化与立体入库工作站
- **项目背景 (S/T)**：针对新能源电池模组段多型号换型慢、热压温控波动大及人工分拣溯源难等痛点，独立承担全套 PLC 控制系统架构设计、PROFINET 组网、标准功能块封装与 WinCC SCADA 联调交付。
- **核心动作 (A)**：
  1. 搭建 S7-1215C + ET200SP + TP700 + SINAMICS G120/V90 + 智能视觉相机的 PROFINET RT 实时网络，规范编制 I/O 点表与 UDT 数据模型；
  2. 采用 **OMAC PackML + GRAFCET** 双层状态机架构开发主控 SCL 程序，通过多重背景（Multi-Instance）封装标准化气缸块（含超时与双磁簧互斥检测）及 G120 报文 1 驱动块；
  3. 将热压腔闭环温控部署在 `OB30 (100ms)` 恒定循环中断中，结合抗积分饱和算法与超温硬/软双重回差联锁；利用优化 DB 变量级 `RETAIN` 特性保障 4×3 立体库托盘条码断电零丢失。
- **量化成果 (R)**：实现 3 种锂电模组一键配方换型，单件节拍稳定在 **11.2s（UPH > 320）**，热压腔恒温精度达 **85.0°C ±0.3°C**，通过完整 FAT 故障注入验收与 72h 连续运行零卡滞。

## 二、面试官必追问 15 题速查索引

1. **为什么气缸控制块 `FB_Cylinder2Pos` 要写成 FB（功能块）而不是 FC（函数）？**
   → 气缸需要保存内部定时器（`TON`）状态、目标命令锁存及故障锁存等跨周期“记忆数据”，FB 拥有专属静态变量 `Static` 和背景 DB，并支持在主控 FB 中采用多重背景（Multi-Instance）实例化多个气缸，代码零重复、DB 树极度整洁。
2. **S7-1215C 控制 SINAMICS G120 变频器和 V90 伺服分别使用什么报文？控制字 `16#047E` 和 `16#047F` 是什么含义？**
   → G120 速度控制使用 PROFIdrive **标准报文 1 (2 PZD)**，`16#047E` 表示准备就绪/OFF1 停机（Bit10=1 声明 PLC 主控），上升沿发 `16#047F`（Bit0=1）启动运行，故障复位发 `16#04FE`（Bit7=1）；V90 定位控制可用**标准报文 3**（搭配 PLC 工艺对象 TO + `MC_Power/MC_Home/MC_MoveAbsolute`）或**西门子报文 111**（EPOS 驱动器内部定位 + `SINA_POS`）。
3. **热压温控 `PID_Compact` 为什么要放在 `OB30` 循环中断里，而不能放在 `OB1` 主循环里？**
   → PID 离散积分 `Ki * e * Δt` 与微分 `Kd * Δe / Δt` 高度依赖严格恒定的采样周期 `Δt`；`OB1` 扫描时间会随逻辑分支和通信负载抖动，放进 `OB1` 会造成调节周期漂移、温度超调震荡；`OB30` 按硬件定时精确触发（如 100ms），保证闭环稳定性。
4. **断电重启后，4×3 立体库的 12 个仓位占用状态与电芯条码怎么防止丢失？`OB100` 里要注意什么坑？**
   → 在启用“优化的块访问”的 `DB_StationGlobal` 中对 `WarehouseSlots` 和 `ActiveRecipe` 开启变量级 `RETAIN`（掉电保持，写入 CPU 超级电容/非易失保持区）。`OB100` 上电初始化时**绝不能把整个结构体清零**，只允许刷新固定的机械坐标 `(PosX, PosZ)` 和清零瞬态按钮命令！
5. **在你的 PackML 状态机里，“急停拍下 (`Abort`)”和“普通暂停 (`Hold`)”是怎么区分处理的？**
   → `Hold` 是工艺级受控暂停：安全减速、保持当前 `#statStep` 步序记忆、加热可保温，恢复 `Unhold` 后原地续跑；`Abort`（急停）属于安全级无条件切断：硬件安全继电器断开动力/STO、强制关闭加热输出、把 `#statStep` 清零，必须排除危险后经 `Clear → Stopped → Reset` 全面回零才能重启。
6. **为什么急停按钮和停止按钮在现场接线必须用常闭触点（NC），而不是常开触点（NO）？**
   → 遵循工业故障导向安全（Fail-Safe）原则：正常态闭合输入为 1，一旦发生急停线松脱、断线、24V 掉电或触点氧化，PLC 立刻读到 0 并触发安全停机；若用常开，断线时拍急停根本停不下来！
7. **什么是“双线圈输出”？为什么在 PLC 扫描周期里会导致极其隐蔽的现场 Bug？**
   → 同一物理输出地址（如 `%Q0.0`）在 OB1 中被多处赋值，因为 PLC 遵循 `PII锁存 → OB1从上到下修改PIQ → 周期末尾PIQ统一写硬件` 的规则，前一个网络的结果会被后一个网络静默覆盖（Last-Write-Wins），在线监控时看似上面网络导通，物理继电器却完全不吸合。
8. **气缸双磁簧开关同时导通（粘连故障）为什么要加 150ms 滤波定时器 `TON`？**
   → 防止短行程气缸极速切换或信号电磁瞬态干扰引起误报，同时 150ms 足以可靠捕获磁性开关损坏粘连或接线短接，一旦触发即报 `103` 故障并切断双侧电磁阀防止误判定到位引发撞机。
9. **你的优化数据块（Optimized Block Access）和非优化数据块有什么区别？什么时候必须取消优化？**
   → 优化 DB 按变量数据类型自动对齐排布内存、无绝对字节偏移、访问速度更快且支持单变量独立勾选 `RETAIN`；仅当需要与老式不支持符号寻址的第三方上位机、S7-300/400 `PUT/GET` 或旧版 WinCC 通过绝对地址（如 `DB1.DBD0`）通信时才取消优化。
10. **热压腔超温报警（≥95°C）后为什么不能温度一掉到 94.9°C 就自动恢复加热？**
    → 必须设计**锁存 + 迟滞回差（Hysteresis）**：超温可能是 SSR 击穿粘连或风冷故障导致的，若自动恢复会反复高温干烧电芯引发热失控；因此超温后强锁存，必须排查隐患并等温度降至安全回差（如 90.0°C）以下，再由人工按复位键解锁。
11. **V90 垂直 Z 轴伺服为什么必须选配带电磁抱闸的电机？急停时怎么防止重力坠落？**
    → 垂直轴断电后受机械臂与模组重力作用会自由下落砸毁模具；必须选配 24V 失电制动抱闸电机，由 V90 驱动器按抱闸时序控制（先建励磁再开闸、先合闸再撤使能），急停时硬件切断 STO 同步失电锁死抱闸。
12. **PROFINET 现场调试最常见的“全站闪红灯报找不到 IO 设备”是什么原因？怎么排查？**
    → 80% 是因为**只分配了 IP 地址，没在线分配 PROFINET 设备名称（Device Name）**，或设备名称与硬件组态里的大小写/短横线不一致；排查顺序：在线可访问设备核对名称与 IP → 查网线水晶头/屏蔽接地 → 查 GSDML 版本与固件匹配 → 查诊断缓冲区（Diagnostics Buffer）。
13. **如何防止热压温控 PID 在冷机升温阶段出现严重温度过冲（Overshoot）？**
    → 采用**抗积分饱和（Anti-Windup）**策略：当 PID 输出达到 100% 满功率限幅且误差仍为正时停止积分累加（或积分分离，仅在误差小于 ±8°C 时切入积分项），配合西门子 `PID_Compact` 预调节+精确调节，将超调压在 0.3°C 以内。
14. **现场气缸打点测试和联动前，你有一套怎样的防撞安全调试步骤？**
    → 严格执行“五步法”：① 断电查线测通断防短路 → ② 上电不供气/低速点检全部 DI/DO 极性与方向 → ③ 降气压（0.2MPa）单动点动气缸、核对电磁阀与磁簧对应关系 → ④ 伺服点动测旋向、软硬限位与回零 → ⑤ 降速 20% 空跑自动流程，最后提速至 100% 带料做 FAT 故障注入。
15. **如果客户现场要求新增 1 个立库列数（4×3 变 5×3）或再加 2 个气缸，你的软件架构改造成本有多大？**
    → 极低！得益于模块化架构：新增气缸只需在主控 FB 的 `Static` 区新增 2 个 `FB_Cylinder2Pos` 多重背景实例并绑定 I/O；立体库扩容只需将 `WarehouseSlots` 数组上限从 12 改为 15、调整 `OB100` 坐标映射公式与循环上限常量，核心状态机与 HMI 报警框架完全复用。
