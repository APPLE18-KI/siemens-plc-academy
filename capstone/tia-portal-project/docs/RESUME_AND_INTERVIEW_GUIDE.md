# 简历项目写法与 15 道面试高频追问整理

## 一、STAR 简历项目经历参考（按岗位按需删减）

### PLC 电气自动化工程师方向
- **项目名称**：新能源锂电模组柔性视觉分拣、热压固化与立体入库工作站（S7-1215C + PROFINET）
- **项目背景与职责**：针对动力电池模组后段多型号换型、热压恒温控制和 4×3 立体库条码追溯需求，独立承担从 URS 节拍拆解、电控 BOM 与 I/O 点表定型、模块化 SCL 编码到 FAT 故障注入验收的整站开发。
- **核心实施内容**：
  1. 基于 SIMATIC S7-1215C（`6ES7 215-1AG40-0XB0`）搭建 100Mbps 星型 PROFINET IO 网络，接入 TP700 HMI、ET 200SP 分布式 IO、智能视觉相机、SINAMICS G120 变频器及 2 台 V90 伺服；编写 G120 标准报文 1 控制块（处理 `16#047E -> 16#047F` 启停时序与 `16#4000 = 16384` 转速标定）和 V90 X/Z 双轴定位接口（Z 轴配 24V 失电抱闸）。
  2. 用 SCL 实现 OMAC PackML 外层状态管理（区分工艺暂停 `Held` 保留步序与急停 `Aborted` 强清步序）和内层 5 步 GRAFCET 顺控；通过多重背景封装双位气缸块 `FB_Cylinder2Pos`，内置 `T#150ms` 双磁簧互斥滤波、超时报警代码与气缸/伺服防撞互锁。
  3. 将热压固化腔闭环温控部署在 `OB30 (100ms)` 循环中断中消除 OB1 扫描周期波动，加入抗积分饱和 PI 控制与 1.0s SSR PWM 调制，并设置“超温锁存（≥95°C）+ 5°C 降温回差（<90°C）+ 人工确认复位”联锁；在优化数据块 `DB_StationGlobal` 中对 4×3 立库仓位数组开启变量级 `RETAIN` 掉电保持，并在 `OB100` 中只刷新机械坐标、保留在库条码。
- **验收结果**：支持 3 款锂电模组配方换型，单件节拍稳定在 11.2s（UPH > 320），热压腔稳态控温精度 85.0°C ±0.3°C（冷机超调 < 0.4°C）；通过急停断 STO、双磁簧粘连、95°C 超温锁存和断电重启仓位保持等全部 FAT 故障注入测试。

## 二、15 道面试高频追问速查

1. **为什么双位气缸控制块 `FB_Cylinder2Pos` 要写成 FB（功能块），而不是 FC（函数）？**
   要点：气缸需要跨扫描周期记忆命令、`TON_TIME` 超时定时器和互斥故障锁存，FB 拥有 `Static` 静态区与背景 DB，并可在主控 FB 中用多重背景（Multi-Instance）实例化多只气缸。
2. **S7-1215C 控制 SINAMICS G120 和 V90 分别用什么报文？`16#047E` 和 `16#047F` 是什么意思？**
   要点：G120 调速用 PROFIdrive 标准报文 1（2 PZD，`16#4000 = 16384 = 100%`）；Bit10=1 声明 PLC 控制权，先发 `16#047E`（OFF1=0）解除接通禁止，再发 `16#047F`（Bit0 上升沿）启动，故障复位发 `16#04FE`（Bit7 上升沿）；V90 定位用标准报文 3（TO 工艺对象 + `MC_*`）或报文 111（EPOS + `SINA_POS`）。
3. **热压温控为什么放在 `OB30` 循环中断里，而不能放在 `OB1` 主循环里？**
   要点：离散 PID 的积分项 `Ki*e*Δt` 与微分项 `Kd*Δe/Δt` 要求恒定采样周期 `Δt`，`OB1` 会随程序分支和通信波动，`OB30` 按硬件 100ms 准时抢占执行。
4. **断电重启后 4×3 立体库仓位状态与条码怎么防丢？`OB100` 要避开什么坑？**
   要点：优化 DB 中对 `WarehouseSlots` 和 `ActiveRecipe` 开启变量级 `RETAIN`；`OB100` 只清瞬态按钮指令并刷新固定机械坐标 `(PosX_mm, PosZ_mm)`，严禁清零 `.Occupied` 和 `.ModuleBarcode`。
5. **PackML 状态机里，“急停 (`Abort`)”和“工艺暂停 (`Hold`)”怎么区分？**
   要点：`Hold (50)` 受控减速停机、保留 `#statStep` 步序与保温，按 `Unhold` 原地续跑；`Abort (90)` 硬线断 STO 和加热、软件无条件跳 90 并清零 `#statStep := 0`，须经 `Clear -> Stopped -> Reset` 重回零。
6. **急停、停止和安全门开关为什么要接常闭触点（NC）？**
   要点：Fail-Safe 故障导向安全，正常待机 `%I0.0 = 1`，一旦断线、端子松脱或 24V 掉电立刻读到 0 触发停机；常开触点断线时无法检出。
7. **什么是“双线圈输出”？为什么监控前一段导通，现场阀却不动作？**
   要点：PLC 按 `PII 锁存 -> OB1 顺序改写 PIQ -> 周期末尾 PIQ 写硬件` 执行，同一 `%Q` 多次赋值会被后写覆盖（Last-Write-Wins）；同一物理输出全程序只赋值一次。
8. **V90 垂直 Z 轴为什么必须配抱闸电机？抱闸时序谁来管？**
   要点：垂直轴断电失矩会重力下坠；必须选 24V 失电制动抱闸，交由 V90 内部时序控制（先建励磁再延迟 50~100ms 开闸，停机先合闸再撤使能），急停断 STO 同步失电锁死。
9. **热压腔从室温 25°C 升到 85°C 怎么防超调？**
   要点：大惯性电加热初期误差大，易产生积分饱和；在 `FB_ThermalPress_PID` 中做 Anti-Windup（满功率限幅时冻结积分并钳位 80%），或用 `PID_Compact` 先冷机预调节再精确调节。
10. **热压腔超温（≥95°C）后为什么不能降到 94.9°C 自动复热？**
    要点：超温可能源自 SSR 击穿或感温脱落，自动复热会在临界点反复干烧；必须锁存故障、清零 PID 输出与积分，且满足降温回差（5°C，`<90.0°C`）、无断线、人工复位三条件才解锁。
11. **气缸双磁簧互斥检测为什么要加 150ms `TON` 滤波？**
    要点：过滤短行程快速切换和接触器吸合带来的 10~30ms 信号重叠毛刺，避免误停机；超过 150ms 立即锁存 `FaultCode = 103` 并切断双侧电磁阀。
12. **PROFINET 组态下载后 CPU 闪红灯报找不到 IO 设备，排查顺序是什么？**
    要点：先查在线分配的 PROFINET 设备名（Device Name）是否逐字一致 -> 查 CPU 诊断缓冲区确认槽位与 GSDML/订货号 -> 查交换机 Link 灯和网线屏蔽接地 -> 用 PRONETA 排查 IP 冲突。
13. **优化的块访问和非优化 DB 有什么区别？什么时候要关优化？**
    要点：优化 DB 编译器自动对齐内存、支持符号寻址和单变量 `RETAIN`；需要与老版 WinCC、第三方 Modbus/OPC 网关或 S7-300/400 `PUT/GET` 按绝对地址（如 `DB1.DBD0`）通信时取消优化。
14. **立库扩成 5×4（20 仓）或视觉后加 1 只气缸，软件改动成本多大？**
    要点：气缸只需在主控 FB `Static` 区新增 1 个 `FB_Cylinder2Pos` 多重背景；立库扩容只改 `WarehouseSlots` 数组上限、`OB100` 的 `MOD 5` 常量和检索循环上限，不改主状态机。
15. **新装配的非标单机第一次通电怎么防撞机？**
    要点：五步上电法：断电测通断绝缘 -> 仅上控制电完成全量 DI/DO 打点 -> 降气压 0.2MPa 单动气缸核磁簧 -> 伺服 10% 低速点动测旋向、限位、抱闸与回零 -> 20% 降速空跑无干涉后再提速带料做 FAT。
